A few quick notes about using Arc Network and the tools collected here.

What is Arc Network?

Arc Network is an independent portfolio and directory for useful web tools, experiments, and future projects by Tayyab.

Where can I start?

Visit the Projects page or open Free Fire Inventory from the featured work cards on the homepage.

Can I suggest an idea?

Yes. Use the Contact page to send a project idea, question, or collaboration note.

Are the tools affiliated with Garena?

No. The Free Fire tool is an unofficial fan-made utility and is not affiliated with, endorsed by, or sponsored by Garena.
